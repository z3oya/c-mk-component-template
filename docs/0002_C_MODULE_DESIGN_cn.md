# 0002 C 模块设计文档规范

C 模块设计文档必须包含以下四节。

## 1. 对外数据结构

- 每个导出的 struct/enum/union 一条：用途与字段表（名称、类型、单位/取值范围、说明）。
- 指针字段须注明内存归属方及其生命周期。

## 2. 对外接口一览表

- 一张表列出全部对外函数：签名、简短说明。

## 3. 对外接口详情

每个函数须说明：

- 参数检查条件：前置条件及非法输入时的行为（返回值 / 断言 / 忽略）。
- 数据生命周期：由谁分配与释放、数据有效时长、线程安全约束。
- 输入输出行为：每类已定义输入对应的可观察结果；作为测试用例的依据。

## 4. 典型用例

- 每条主要工作流给出一个最小可编译示例。
