# 0001 Basic Rules

1. All non-third-party C language files must comply with the file conventions of template.c / template.h; the format itself must not be reduced in any form.
2. Every document under docs/ must carry a four-digit hexadecimal prefix (0000-FFFF), and file names must not contain non-ASCII characters. The 00XX range is reserved for general conventions, where English file names are all uppercase. Independent bilingual files are not mandatory, but a Chinese document must take the _cn suffix.
